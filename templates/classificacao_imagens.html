Etapa 3

Preparação das Imagens

Todas as imagens precisam ter o mesmo formato para entrar na rede neural.

1. RGB

Padroniza todas as imagens para 3 canais de cor.

2. Redimensionamento

Transforma imagens de tamanhos diferentes em uma dimensão única.

3. Normalização

Converte pixels de 0–255 para valores entre 0 e 1.
